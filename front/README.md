# GreenLib Resource Management System

A production-ready, emerald-themed resource management system for educational institutions. This application features Role-Based Access Control (RBAC), Dark Mode, and responsive layouts.

## 🚀 Key Features
-   **Student View**: Access, read online, and download various learning materials.
-   **Librarian Workspace**: Dedicated upload workflow for official textbooks and library books.
-   **Teacher Workspace**: Upload class documents, assignments, and syllabi targeted to specific groups.
-   **Admin Control Center**: Manage system users, permissions, and generate detailed usage reports.
-   **Responsive Design**: Optimized for mobile, tablet, and desktop views.
-   **Theming**: Beautiful Emerald-based color palette with specialized Dark Mode.

## 🛠️ Tech Stack
-   **Frontend**: React (Vite)
-   **Styling**: Tailwind CSS
-   **Icons**: Lucide React
-   **Routing**: React Router DOM
-   **State**: Context API for Authentication and Theme logic
